TCB란?
(Task Control Block / Thread Control Block)
: task 상태, 우선순위, 스택포인터 등 실행 필요한 모든 정보 저장 구조체

CPU Register 값을 스택에 복사 
- TCB 를 이용하여 Task 를 수행할 수 있고 (프로세스개념) 
- task 안에서 stack은 context 들을 저장함
- 종료될 경우 stack 안에 있는 cpu 레지스터 정보들을 토대로 context switching 진행

FreeRTOSConfig.h 
- 필요 없는 기능 비활성화로 코드 크기 및 메모리 절약 가능


vTaskDelete : task 삭제 ( param NULL 은 자기자신)
vTaskPrioritySet()  : task 우선순위 변경 ( param NULL 은 자기자신)
vTaskSuspend: task 중지 
vTaskResume: task 재개 (준비 상태로 이관)

vTaskDelay (1000) : 시간 인터럽트가 1000번 발생 / 상대적 시간 개념
vTaskDelay (PdMS_to_Tick(1000)) : 절대적 시간 개념
vTaskDelayUntil (TickType 구조체 변수) : 절대적 시간 개념
- 일정 시간마다 특정 함수 진행
